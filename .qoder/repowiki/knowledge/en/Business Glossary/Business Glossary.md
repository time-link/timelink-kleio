### Kleio
- Definition：A specialized text notation created by Manfred Thaller for transcribing historical sources, designed specifically for genealogical and historical document processing. Files use indentation-based hierarchical structure with group names followed by dollar signs (e.g., `fonte$`, `acto$`, `n$`) to represent entities and their relationships.
- Aliases：Kleio notation、Kleio files

### semantic tests
- Definition：Test methodology that compares translation outputs between the legacy stable translator (using `.str` structure files) and the new dev translator (using YAML structure definitions) to identify structural and semantic differences during the schema migration process.
- Aliases：semantic comparison、translation diff

### linked data
- Definition：External identifier annotations in Kleio files using `@short-name:id` syntax (e.g., `@wikidata:Q17057616`) that get resolved to full URLs during translation, creating separate resolution groups in the output XML with entity links and original values preserved.
- Aliases：external links、@wikidata references

### referido
- Definition：A special person reference group used within events to indicate the subject or target of an action, distinct from regular person groups. In the dev translator, these automatically generate function-in-act relation groups linking back to the source.
- Aliases：referido person、event subject

### viagem
- Definition：A travel event group type that should contain persons (viajante) and their attributes. Currently has a schema definition bug where it only allows `referido/referida` but not `person/n` groups, causing incorrect nesting of travelers in the dev translator.
- Aliases：travel event、pevent specialization

### genealogias
- Definition：Genealogy-specific source files that use groups like `titulo`, `genealogia`, `casal`, `marido`, `mulher`, `filho`, `filha` which are not defined in either the legacy `.str` or new YAML schemas, requiring additional schema definitions before they can be processed.
- Aliases：genealogy files、family records

### felgaio
- Definition：A documentation section comment in the legacy structure file describing genealogy-related groups prepared for Felgueiras Gaio records, not an actual group definition itself.
- Aliases：Felgueiras Gaio section

### ls attribute
- Definition：Linked data attribute group in the XML output that contains external identifiers, types, values, dates, and entity information. Dev translator creates separate resolution groups for linked data while stable translator embeds references as comments.
- Aliases：linked attribute、external link attribute

### function-in-act
- Definition：A relation type automatically generated by the dev translator for `referido` persons, creating explicit relation groups that link the referenced person back to the source act, which the stable translator does not produce.
- Aliases：auto-relation、referido relation

### schema migration
- Definition：The ongoing process of converting structure definitions from the legacy `.str` format to YAML format, tracking semantic differences between stable and dev translators through systematic testing and comparison.
- Aliases：YAML migration、structure conversion
