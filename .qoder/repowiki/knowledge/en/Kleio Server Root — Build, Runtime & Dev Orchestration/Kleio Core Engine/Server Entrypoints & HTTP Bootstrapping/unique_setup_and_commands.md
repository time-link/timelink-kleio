Each entrypoint is launched directly via `swipl -f src/<file>.pl -g <goal>` (e.g. `swipl -f src/serverStart.pl -g run_server_forever`). Server behaviour is controlled entirely by KLEIO_* environment variables (`KLEIO_SERVER_PORT`, `KLEIO_DEBUGGER_PORT`, `KLEIO_ADMIN_TOKEN`, `KLEIO_WORKERS`, `KLEIO_IDLE_TIMEOUT`, `KLEIO_CORS_SITES`, etc.); `run_test_server/0` additionally rewrites the working directory into a `tests/kleio-home` layout before starting.
