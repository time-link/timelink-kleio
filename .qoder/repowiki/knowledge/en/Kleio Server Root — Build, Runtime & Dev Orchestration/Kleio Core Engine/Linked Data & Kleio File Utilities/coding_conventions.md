- Directory-resolution predicates follow a fixed precedence chain: try an environment variable first, then fall back through known container paths (`/kleio-home`, `/timelink-home`, `/mhk-home`), then working-directory heuristics, finally `~/...` — each clause ends with a cut or succeeds/fails deterministically.
- Path-mapping predicates (`kleio_resolve_source_file/3`, `kleio_resolve_structure_file/3`) are written as multi-clause bidirectional mappers that handle empty string, atomic relative, and atomic absolute inputs separately rather than normalising up-front.
- File-set construction uses a uniform `Type(Attributes)` term list (`kleio`, `rpt`, `err`, `xml`, `org`, `old`, `ids`, `'files.json'`) where attributes are built via `file_attributes/2` and later converted to relative form by mapping over option keys with `file_attributes_relative/3`.
- Thread-local dynamic facts are declared with both `:-dynamic` and `?-thread_local` directives so they can be asserted/retracted without leaking across threads.
