Two cooperating sub-directories under `tests/`:
- `scripts/` — a set of POSIX shell scripts forming a layered pipeline. `env_tests.sh` is the single source of truth for all paths (`KLEIO_HOME`, `REFERENCE_SOURCES`, `TEST_TRANSLATIONS`, `STABLE_CODE_DIR`, `DEV_CODE_DIR`, …) and is `source`d by every other script. `prepare_tests.sh` cleans and bootstraps `kleio-home/sources/{reference_sources,test_translations}` plus a working copy of the dev translator in `dev/`. `run_tests.sh` is the top-level orchestrator: it invokes `prepare_tests.sh`, runs the stable translator locally against `REFERENCE_SOURCES`, then starts the dev server via `kleio_start_server.sh`, translates the same inputs remotely through `kleio_translate_remote.sh`, stops the server with `kleio_stop_server.sh`, and finally delegates to `compare_test_results.sh` which diffs `REFERENCE_TRANSLATIONS` vs `TEST_TRANSLATIONS` while filtering noise via `exclude_while_comparing.grep`. Helper scripts exist for convenience (`clean_tests.sh`, `redo_run_tests.sh`, `run_stable_translations.sh`, `run_remote_translations.sh`, `test_files.sh`) and for running the suite from outside the repo (`run_tests_local.sh`).
- `reports/` — timestamped `.diff` artifacts produced by `run_tests.sh`; each file captures the full `diff -r` output between the stable baseline and the current build.
- `collection.json` — a standalone Postman v2.1 collection exercising the Kleio JSON-RPC/REST endpoints (token lifecycle, directory/file operations, translation jobs) using bearer tokens and environment variables; it is independent of the shell harness and targets the live server on port 8088.

Dependency direction is strictly one-way: entry scripts → helpers → shared env; no cross-imports between `scripts/` and `reports/` or `collection.json`.
