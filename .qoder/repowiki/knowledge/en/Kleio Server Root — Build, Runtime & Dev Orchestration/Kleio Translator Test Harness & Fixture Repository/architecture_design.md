The `tests/` tree is split into two parallel Prolog test suites — `dev/` (current development code) and `stable/` (frozen baseline) — both driven by the same shell harness in `tests/scripts/`. The harness (`run_tests.sh`, `run_stable_translations.sh`, `run_remote_translations.sh`) starts the Kleio server via `kleio_start_server.sh`, launches each suite with SWI-Prolog's `plunit`, then diffs their outputs using `compare_test_results.sh` to catch regressions. Both suites consume the identical fixture repository under `tests/kleio-home/`, which provides `.kleio` sources, YAML structures, mappings, and expected outputs so that dev vs. stable runs exercise the same data. The `api/postman/` directory is an independent Postman collection/environment pair that targets the same running server for REST/JSON-RPC endpoint tests, complementing the Prolog-driven functional tests.
