
# kleio-server

The API is provided in a REST in REST and JSON-RPC versions.

Not all functions are provided in both versions.

In general functions that require sending structured input are exposed in JSON-RPC (tokens and users) while simple file fetching functions have only a REST version (exports, reports).

A client would preferable use JSON-RPC and call REST to fetch files.
